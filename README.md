# 🚀 TechNova Solutions

> Portal institucional desenvolvido para a **TechNova Solutions**, uma startup brasileira especializada em soluções digitais inovadoras.

---

## 📋 Sobre o Projeto

O **TechNova Solutions** é um website institucional moderno e responsivo, projetado para apresentar os serviços, a cultura e os canais de atendimento da empresa. O foco do projeto é oferecer uma navegação intuitiva e uma interface alinhada às boas práticas de desenvolvimento web.

### 💡 Áreas de Atuação
* **☁️ Computação em Nuvem (Cloud Computing):** Infraestrutura escalável e segura para negócios digitais.
* **🤖 Inteligência Artificial:** Automação inteligente e análise avançada de dados.
* **🛡️ Cibersegurança:** Proteção de dados, redes e sistemas corporativos.

---

## ✨ Funcionalidades

* **Navegação Intuitiva:** Menu principal estruturado para acesso rápido às seções.
* **Apresentação Institucional:** Banner principal e seção *Sobre Nós* apresentando a missão e a equipe da startup.
* **Catálogo de Serviços:** Detalhamento das soluções oferecidas nas áreas de Cloud, IA e Segurança.
* **Tabela Comparativa de Planos:** Visão clara das opções de contratação disponíveis.
* **Blog Tecnológico:** Espaço dedicado a artigos, novidades e tendências do setor.
* **Contato e Localização:** Formulário interativo para atendimento e mapa integrado.
* **Design Responsivo:** Layout adaptável para desktops, tablets e dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização, layout (Flexbox/Grid) e responsividade.
* **Visual Studio Code:** Ambiente de desenvolvimento.
* **Git & GitHub:** Versionamento de código e hospedagem via **GitHub Pages**.
